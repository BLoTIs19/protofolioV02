Put your screenshots, GIFs and video files in this folder.

Then reference them in the site as:
  assets/my-game/screenshot.png
  assets/my-game/gameplay.gif
  assets/my-game/trailer.mp4

GitHub has a 100 MB per-file limit and repos work best under 1 GB total,
so host long videos on YouTube and paste the link instead of committing
the .mp4 here.
